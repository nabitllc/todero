# Skill Builder Protocol

When I fail at a task, do it poorly, or lack a capability:

1. **Stop and acknowledge** the failure clearly
2. **Diagnose** what's missing (tool, context, process, API)
3. **Build a skill or solution** to fix it permanently:
   - If it needs a new CLI tool → install it
   - If it needs better instructions → create/update a SKILL.md
   - If it needs a new process → document it in workspace
   - If it needs an API → prompt Michael for the key
4. **Test** the fix before reporting success
5. **Document** what was built in memory/YYYY-MM-DD.md

## Examples of when to trigger this
- "I can't read your Gmail" → install himalaya, set up gog auth
- "I keep forgetting X" → update MEMORY.md with a reminder rule
- "My Discord messages are poorly formatted" → update discord SKILL.md
- "I can't summarize PDFs" → install nano-pdf skill

## Never say "I can't do that"
Always say "I can't do that yet — here's how I'll fix it" and then fix it.

## Critical Bugs Fixed

### Bug 1 — Context loading was completely broken (≥several weeks)
`/api/run-agent/route.ts` line 192 had:
```ts
const context = `$(cat ${WORKSPACE}/SOUL.md ${WORKSPACE}/AGENTS.md ...)`
```
This is a TS template literal producing a **literal string** `$(cat ...)`. It then got single-quoted into the shell exec, so the shell never evaluated `$(cat ...)`. **Every agent for weeks received the literal text `$(cat …)` instead of file contents.** No SOUL, no AGENTS, no memory. Explains why Builder kept forgetting to PATCH status — the rule was never in the prompt.

**Fix:** `fs.readFileSync` in Node at spawn time. Verified: ps aux on spawned builder now shows full SOUL content inlined.

### Bug 2 — LaunchAgent schedules interpreted Hour as UTC but launchd uses local
- `com.nabit.sprint-cycle.plist` had `Hour=10 Minute=55` with comment "= 10:55 UTC" → actually ran at 10:55am EDT every day (not 6:55am as intended)
- `com.nabit.pr-window.plist` had `Hour=11` and `Hour=23` → ran at 11am/11pm EDT (not 7am/7pm)

**Fix:** `Hour=6 Minute=55` for sprint-cycle; `Hour=7` and `Hour=19` for pr-window. Reloaded both.

**Lesson (promote to self-improving):** `StartCalendarInterval` is ALWAYS local time. No `TimeZone` key in launchd plists. Do NOT write UTC values.

Script was PATCHing with `transitioned_by: "monitor-stale"` but the workflow validator requires `transitioned_by == current assignee`. Every recovery attempt was returning 400 and logged as failure but never alerted.

**Fix:** `transitioned_by = issue.assignee` (fall back to "builder"). Filed TOD-797 for watchdog-on-watchdog so this can never silently fail again.

## Architectural Findings

### Todero agents are function calls, not processes
OpenClaw's agents were long-running daemons with persistent session state. Todero's are `claude --print` one-shots. Every invocation is a stranger with no memory of the previous task. **This is the root cause of 80% of recent bugs** (forgets to PATCH, forgets corrections, loses context on chaining). Epic TOD-794 tracks the fix.

### Runtime is hardcoded to Claude Code CLI
`/api/run-agent/route.ts` shells out to `/Users/kemuniagent/.local/bin/claude`. Not portable to Codex/Cursor/OpenAI-API. Contradicts Todero's positioning as "use whatever LLM you prefer." Epic TOD-793 tracks.

### No Inbox
Agents have no way to ask humans mid-task. They mock-and-move-on (wrong work) or die. Phase 3 of master plan. Epic TOD-792 tracks.

### Skills regression vs OpenClaw
1,812 lines of skill docs existed at `~/kaos-config/skills/` but were never loaded by the pipeline. OpenClaw loaded them every turn of a persistent session; Todero's stateless spawns never read them. Fixed in R1 by inlining into prompt, but persistent-session model (TOD-794) is the real fix.

### Critical Learning (promote to patterns)

**Branch drift from Builder spawns.** The Builder spawn command runs `git checkout -b feat/tod-X` inside the shared Todero working directory. Since all agents share the same filesystem, a spawned Builder on TOD-776 switches the whole working tree to feat/tod-776 even while I'm editing main. This happened 3+ times this session — I'd commit to main, then a spawn would switch the working tree, and my next rebuild would be on the wrong branch.

**Workaround for now:** before every rebuild, run `git branch --show-current` and `git checkout main` if needed. Don't fire spawn requests while writing code.

**Real fix (TOD-XXX to file):** Use `git worktree add` so each agent gets its own isolated working directory. The spawn command should point at `~/todero/../agent-worktrees/<agent>-<timestamp>/` instead of `~/todero`. This unblocks parallel agent work without filesystem collisions.

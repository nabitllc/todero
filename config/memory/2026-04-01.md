### Blocked field redesign (decided)
- `is_blocked` = boolean flag (default false), NOT a status
- `blocked_by` = UUID only (must reference an existing issue); if no issue exists, use is_blocked=true + add a comment
- `blocks` = auto-maintained reverse relationship (when B.blocked_by = A.id, A.blocks includes B)
- `blocked_from` = status to resume at after unblock (to avoid resetting to open)
- `status=blocked` to be RETIRED — it's a field, not a status
